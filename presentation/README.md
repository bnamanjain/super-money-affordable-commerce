# Affordable Commerce Presentation

This folder produces the editable leadership presentation and timed narration.

## Outputs

- `output/super-money-affordable-commerce-pitch.pptx`
- `output/intro-video-speaker-notes.md`

Slides 1-7 form the recommended three-minute introduction. Slides 8-11 are an
appendix covering Credit Health, experiments, APIs/schema, and risk controls.

## Rebuild

```bash
npm install
npm run build
```

The deck uses screenshots produced by the prototype release suite in
`../prototype/test-artifacts/`.
