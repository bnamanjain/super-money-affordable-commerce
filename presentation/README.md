# Affordable Commerce Presentation

This folder produces the editable presentation for the intro video.

## Outputs

- `output/super-money-affordable-commerce-pitch.pptx`
- `output/intro-video-speaker-notes.md`

Slides 1-11 form the recommended 5:30 to 6:10 recorded story. Slides
12-15 are a technical appendix covering architecture, schema, APIs, and risk
guardrails.

## Rebuild

```bash
npm install
npm run build
```

The deck uses screenshots generated by the prototype verification suite in
`../prototype/test-artifacts/`.
